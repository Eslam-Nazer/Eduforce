## Collaboration workflow

- The user edits the DBML and diagram directly on dbdiagram.io.
- Use this URL to inspect the latest available diagram when reviewing database design or when the user asks to check their changes.
- Review tables, relationships, constraints, and business-rule coverage, and suggest improvements in the conversation.
- Current assistant access is read-only; editing the hosted diagram is not part of this workflow.
- Reviews happen on request, not through automatic monitoring.

The linked resource is a diagram named `Eduforce_db`; do not assume it is a team workspace. If the current schema cannot be read, state that limitation rather than inferring its contents.
